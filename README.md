# 🎵 Spotify Clone – Web Player for Music

A responsive, visually appealing **Spotify Clone** built using **HTML** and **CSS** that mimics the layout and functionality of Spotify's web player UI. This static project replicates key UI components such as the sidebar, music player, library, playlists, and trending sections.

---

## 🌐 Live Preview (Optional)

👉 [Click here to view live](https://jasiiin999.github.io/spotify-clone/)  

---

## 📌 Features

- 🎧 Sidebar with navigation (Home, Search, Library)
- 🗂️ Liked Songs and Playlists section (mobile-friendly)
- 🎶 Recently Played and Trending Sections
- 📊 Featured charts with card UI
- 🎼 Sticky top navbar and responsive buttons
- 🎛️ Fully designed bottom music player with playback controls
- 📱 Mobile view support with optimized layout

---

## 🛠️ Technologies Used

- **HTML5** – Semantic page structure  
- **CSS3** – Styling, layout, and responsiveness  
- **Font Awesome** – For high-quality icons  
- **Google Fonts** – Clean and modern Montserrat font  

> ⚠️ This project is fully static — no JavaScript or dynamic audio playing.
